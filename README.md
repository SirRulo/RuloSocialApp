# RuloSocialApp

TP2 de Programación IV (UTN FRA, 2026 C2): red social con front en Angular y back en NestJS + MongoDB + JWT.

| Carpeta | Qué es | Desarrollo |
|---|---|---|
| `backend/` | API en NestJS 12 (CommonJS, Jest) con MongoDB Atlas | `npm run start:dev` (puerto 3000) |
| `frontend/` | App en Angular 22 | `ng serve -o` |

El `backend/` necesita un archivo `.env` (no está en el repo) con `CONNECTION_STRING` y `JWT_SECRET`.
